## 1.1 小鲸鱼阶段

目标：可爱的蓝色小鲸鱼、真实中文语音、桌面自主跑动；保留听歌、拖拽、透明区域穿透和形象导入。

| 用户可见行为 | 功能验证 | 视觉 / 证据 |
| --- | --- | --- |
| 默认蓝色胖鲸鱼 | 新设置和旧设置迁移、主题切换往返 | 初始真实 Electron 窗口；眼睛、肚皮、尾鳍 |
| 摸摸 / 喂食 / 说句话 | 从宠物及小屋操作，好感和文案更新 | 微笑、爱心、说话张嘴 |
| 中文语音 | 本地声线枚举、真实 speak-start/end、静音、取消；生成 WAV 检查非静音 | 声音面板、说话气泡；物理扬声器听感需用户体验 |
| 跑一圈 / 自主散步 | 原生窗口位置实际变化、左右折返、开关往返 | 跑动中帧及停止帧、方向与尾鳍一致 |
| 交互不被跑动干扰 | 鼠标靠近停止、拖拽抢占、睡觉停止、唤醒 | 悬停控制条和睡眠表情 |
| 透明穿透 | 实际命中函数：本体命中、四角/影子不命中；原生 ignore 状态 | 透明截图；物理跨应用点击单独说明 |
| 工坊全部控制 | 四个页签、三档尺寸、主题、开关、音量/声线、恢复位置 | 默认大小与最小窗口下无截断 |
| 听歌联动 | SMTC 桥接真实状态、播放状态下动作与歌词；异步歌词切换 | 有 / 无播放器状态 |
| 自定义素材 | 导入图片切换回内置；不支持的文件与取消处理 | 导入空状态及启用状态 |

探索场景：连续摸摸时取消上一句语音；拖拽中关闭散步；睡觉时点击跑一圈；关闭全屏隐藏后恢复；重复启动；设置保存与重启。

本表为验证计划。具体通过项、证据与未实测范围见本轮完成后填写的验证记录。

本轮已执行。完成项、实际截图与尚未覆盖的外部场景见 [验证记录](验证记录.md)。隔离测试已关闭，日常版本已打开。
