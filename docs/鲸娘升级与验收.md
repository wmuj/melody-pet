# 鲸娘升级与验收 · MelodyPet 1.2

2026-11-13。用户明确选择优先增强可爱程度、动作和互动；随后用 `fornarwhal/deepseek-whale-girl-icon` 纠正角色为蓝发鲸娘，并提供 `GarfieldZhung/DeepSeek-Whale-Girl` 与 codex-pets.net。

## 设计与范围

- 保留蓝发、白色褶边头饰、海军蓝女仆裙和鲸尾。默认角色使用 `fornarwhal/deepseek-whale-girl-icon` 的 984×984 独立原图，以及 `GarfieldZhung/DeepSeek-Whale-Girl` 的约 640 像素互动姿态；不把社区二创称为本项目原创或官方角色。
- 原小鲸鱼和三套猫咪继续可选；已有昵称、亲密度、声音和素材保留。
- 动画由高清姿态、表情遮罩、呼吸、跑动网格形变和原生窗口移动共同组成。完成眨眼、中文出声时简单嘴形开合、睡醒、左右跑动、拖放回弹、轻微朝向鼠标和喂食反馈；没有把完整逐帧动画或挥手序列列为已完成。
- 本地中文台词增加情境与近期避重复。相处记录仅保存本应用的互动和经主进程确认的播放事件，可查看、清空。
- Codex Pets V1/V2 的 ZIP 或 pet.json 导入。导入器校验图集规格，不执行包内代码。
- 不配置模型账号、麦克风或付费服务。

小屋继续使用现有蓝白配色：纸白 #f8faff、海蓝 #5487da、鲸蓝 #77a5e3、深蓝 #30425b、柔粉 #c97997。中文用 Microsoft YaHei UI 与 Segoe UI；左侧角色、右侧设置，记忆页采用时间顺序。避免把多种状态伪装成互不关联的小卡片。

## 用户截图所指出的问题与修正

1. **尾巴截断与左侧多余角色**：最初接入的 GMS Codex V2 图集中，部分 look 方向帧本身存在裁切和邻格角色残片。错误帧示例保留在 `references/deepseek-fat-fish-codex-pet/problem-look.png`。默认渲染改用独立 PNG，通用图集渲染器也停止自动调用 V2 look 行。
2. **放大后不清晰**：旧图集为 1536×2288，但每个动作只有 192×208。默认待机／表情改用 984×984，互动姿态为 640×591、640×600、640×616、610×640；Canvas 按真实 `devicePixelRatio` 绘制。没有把简单放大后的尺寸当作新增细节。
3. **白色工具卡片过大**：改为角色下方的悬停操作条与独立迷你播放条，桌面不再固定显示亲密度卡片。亲密度放在小屋里。
4. **歌词卡在制作名单**：本机真实 `cloudmusic.exe` 会话提供歌曲和 Playing 状态，但 `positionMs`、`durationMs` 均为 0。现在只在时间轴有效时显示同步歌词，并过滤作词／作曲等名单；对当前客户端没有宣称歌词已准确同步。

原始素材、早期方案和测试证据保留，没有覆盖用户截图。完整素材署名、上游声明与本地修改见 [来源说明](../THIRD_PARTY_NOTICES.md)。

## 当前范围和限制

- 当前完成的是高清独立姿态配合程序动画，仍需要更完整的动作帧和转场打磨，不能据此宣称已经超过网易云或成熟桌宠。
- 竞品未安装实测；实际物理扬声器听感、跨其他应用的鼠标穿透、真实多显示器、100%／200% DPI、游戏全屏和长时间性能未完成本轮实测。
- 真实网易云会话、曲名和播放状态已经观察到；当前客户端缺时间轴，准确歌词同步仍不具备。节拍动作也没有宣称通过真实录屏／听感验收。
- Codex 社区包受其原始分辨率和帧图质量限制；完整透明视频包尚未逐一验证。
- 正常使用档案与隔离测试记录分开。最终启动及设置保留结果见 [验证记录](验证记录.md) 的 1.2 交付段；尚未制作安装包或公开发布。
