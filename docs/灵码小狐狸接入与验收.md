# 灵码小狐狸接入与验收 · 2026-11-13

用户要求把本地 Codex 的小狐狸加入本项目，并补充名字为「灵码」。在本机 `Documents/Codex/2026-10-10/wo-d/outputs/灵码-宠物分享包.zip` 找到对应素材，实际核对为奶白毛色、青蓝眼睛、蓝色尾尖的小狐狸。

## 实现

- 新增内置外观 `lingma`，在伙伴库、外观页、桌宠右键菜单均可选择。
- 原 PNG 图集完整复制到 `src/assets/lingma/`；新增兼容清单与首帧预览。图片 SHA-256 与原包校验文件一致。
- 复用 V2 图集播放器，按已检查的灵码图集启用十六方向视线、说话时的表情帧和闭眼睡眠姿态。其他导入包保持原来的动作配置。
- 灵码的自称、耳朵和尾巴文案随外观切换；昵称、歌名与用户自定义台词原样保留。切回鲸娘后仍使用原有台词。
- 修正睡眠后触摸时自动唤醒动作覆盖触摸回应的问题；鼠标离开管理界面预览后回到正常待机；窄窗口中灵码卡片独占一行，名称不拆行。
- 保留原默认角色、已有形象、用户昵称、日记、亲密度与其他偏好。设置格式仍为 3。

## 实际结果

`npm run build` 通过；`npm test` **11 项通过、0 失败**。新增回归检查覆盖狐狸身份、昵称和歌曲名称不被替换、自定义台词及导入伙伴不受狐狸台词配置影响。日志见 `artifacts/lingma-qa/build.txt`、`tests.txt`。

实际 Electron 验收使用独立档案 `artifacts/lingma-qa/profile/`，结果记录在 `interaction-results.json`：

- 伙伴库启用、外观页在鲸娘／灵码间往返、切换到导入的 V2 伙伴后再回到灵码均通过。图集、预览和桌面角色同步。
- 实际跑动右向 x 224→266，左向 x 1212→1168；分别播放原图集的右跑／左跑动作。真实拖拽使窗口从 (1162,70) 移至 (1212,100)，拖拽姿态与松手恢复通过。
- 摸摸、喂食、睡眠、唤醒和睡眠中摸摸唤醒均通过。睡眠采用第 5 行第 3 帧（从零开始编号），实际闭眼低头，带呼吸和睡眠标记。
- 实际鼠标移动验证全部 16 个视线方向，离开预览后恢复待机。中文试听开始时播放表情帧，停止按钮可终止发声；没有将状态事件等同于人工听感验收。
- 三种尺寸在当前 150% 缩放下分别得到 420×540、510×645、630×765 的画布像素。默认窗口和最小 820×640 窗口均检查；最小内容区 806×604，没有横向溢出，角色、名称和互动按钮完整可见。
- 重启后灵码选择、设置、日记与计数保留。32 秒连续操作完成 12 轮跑动时换形象、睡眠时换形象、摸摸唤醒、说话打断与换形象后唤醒；收集到的 renderer `pageerror` 为 0。

本轮文件选择器测试使用受控的文件路径返回，随后执行真实导入、文件复制与激活流程。右键入口通过真实右键事件触发后读取菜单结构与选中状态验证，原生菜单弹出由测试钩子拦截，未将其描述为系统菜单的完整鼠标操作测试。测试钩子均已恢复。
