本文件按版本追加历史证据。下方首段为 1.1，最新高清鲸娘 1.2 的交付确认在文末；较早的播放器状态不代表最新检查结果。

交付范围：MelodyPet 1.1，蓝色小鲸鱼、中文出声互动、桌面自主散步 / 跑动、可操作的伙伴小屋，以及原有音乐和形象导入入口。

## 构建与自动测试

- `npm run compile:helper`：两个原生助手存在且与源码一致。
- `npm run build`：前端和 Electron TypeScript 检查、Vite 构建、主进程编译通过。
- `npm test`：5 项通过，0 失败。覆盖旧设置补默认值、无效设置、多屏坐标折返、声线回退及真实原生语音输出。
- 原生中文语音：Microsoft Huihui Desktop，zh-CN。生成 6.662 秒、22050 Hz、16-bit、单声道 PCM WAV；RMS 0.01964，确认不是空音频。参数和文件路径记录在 `artifacts/whale-qa/native-speech.json`。

## 实际 Electron 交互

测试通过 Playwright 启动项目本身的 Electron，使用独立档案 `artifacts/whale-qa/profile`。按钮、开关、输入、拖动由普通 Playwright 鼠标 / 键盘接口触发。

- 当前真实 SMTC 状态为 `hasSession: false`。换歌播报用模拟的「小鲸鱼测试曲」事件验证，语音实际由本机引擎合成；本轮未对真实网易云 / QQ 音乐 / Spotify 的播放、切歌、歌词同步逐一实测。
- 实际音频输出的语音事件与非静音 WAV 已验证；未声称人工听过物理扬声器或评价其音色。
- 透明区域在渲染器的实际命中行为已验证；跨其他应用的物理鼠标穿透、真实游戏全屏、实际多显示器拔插需要相应场景验证。
- 边缘的负坐标和多屏工作区边界经自动测试覆盖，本机实测只有一个显示器。
- 本轮实际素材导入覆盖 PNG，未取得完整透明 WebM / GIF 第三方动作包进行逐帧解码兼容验证。
- 本地开发与运行交付，尚未制作安装包或发布到应用商店。
